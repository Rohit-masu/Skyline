# Visual Review — Use After Every UI Phase

Review the actual browser, not just code or a screenshot from the agent.

## First impression
- [ ] Brand feels premium and coherent within 3 seconds.
- [ ] One clear focal point per section.
- [ ] Type hierarchy is strong; body text is readable.
- [ ] Images have intentional crop, scale and colour treatment.
- [ ] No generic AI-looking gradients, excessive pills or random floating cards.

## Layout
- [ ] Consistent container and gutters.
- [ ] Section spacing is intentional and repeatable.
- [ ] Header and CTA are clear.
- [ ] Cards align and have consistent image ratios.
- [ ] Important details are not hidden behind hover-only behaviour.

## Mobile
- [ ] 360px and 390px widths checked.
- [ ] No horizontal overflow.
- [ ] Filters are usable without crowding.
- [ ] Buttons have comfortable touch targets.
- [ ] Hero copy does not overlap critical imagery.
- [ ] 3D is usable or replaced with a designed fallback.

## Accessibility and motion
- [ ] Keyboard navigation works.
- [ ] Focus is visible.
- [ ] Forms have labels and clear errors.
- [ ] Image alt text is meaningful.
- [ ] `prefers-reduced-motion` was tested in the browser.
- [ ] Contrast is sufficient; essential content is not too faint.

## Functionality
- [ ] Every CTA and control works.
- [ ] Loading, empty, error and success states are designed.
- [ ] Direct route refresh works.
- [ ] No broken image or console error.
